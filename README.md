# 🍦 Ice Cream Quiz

An interactive quiz for ice cream fans! Pick a nickname and an avatar, test your knowledge, and climb a shared leaderboard.

## ✨ Features
- 🎮 Kahoot-style entry screen: choose a nickname and one of several preset avatars
- ❓ A set of fun ice-cream-themed quiz questions
- 🏆 Real-time shared leaderboard (powered by Firebase) — visible to all players across devices
- 📱 Responsive design

## 🛠️ Tech Stack
- React + Vite
- Firebase (leaderboard)
- CSS
